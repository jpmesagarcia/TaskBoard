2
Flujo diario recomendado
El ritual de la mañana
1
Abre TaskBoard y revisa "Mi día"
El timeline te muestra reuniones fijas y tareas ★ colocadas automáticamente. La barra de capacidad te dice si estás sobreocupado antes de empezar.
2
Añade las reuniones del día
Botón + Reunión arriba a la derecha. Ponle fecha, hora, duración y proyecto. Las reuniones bloquean huecos en el timeline automáticamente.
3
Ajusta prioridades
En el Listado, haz clic en los badges de prioridad para subir o bajar tareas según el día que tengas. Las ★ aparecerán en el timeline.
4
Guarda en Drive
Pulsa ↑ Guardar Drive para sincronizar. Así tienes los datos disponibles desde cualquier dispositivo.
5
Al final del día, limpia las ★ completadas
Elimina las tareas hechas desde el listado y baja las que no hayas podido hacer a A o C según corresponda.
3
Sincronización con Google Drive
Tus datos siempre disponibles
↓
Cargar Drive
Descarga los datos más recientes desde Google Drive. Úsalo al abrir la app en un dispositivo nuevo o después de que Claude haya generado un JSON actualizado.
↑
Guardar Drive
Sube el estado actual a Google Drive. El botón se pone verde cuando hay cambios pendientes de guardar. Hazlo siempre antes de cerrar si quieres que se sincronice.
⬇
Exportar JSON
Descarga un fichero JSON con todos tus datos. Úsalo para pasárselo a Claude cuando quieras que te ayude a planificar o reorganizar las tareas con IA.
⬆
Importar JSON
Carga un fichero JSON. Úsalo cuando Claude te haya devuelto el JSON con cambios (nuevas prioridades, tareas reorganizadas, etc.) para aplicarlos en la app.
⚠️
El localStorage del navegador guarda los datos automáticamente en cada cambio, así que no los perderás al recargar. El botón ↑ Guardar Drive es para sincronizar entre dispositivos o hacer backup en la nube.
🤖
Usar Claude como capa inteligente
Bajo demanda, cuando lo necesites
📅
Planificar el día
Expórtale el JSON y dile "planifícame el día de hoy". Te dirá qué hacer primero, qué mover y si estás sobreocupado.
📊
Reorganizar prioridades
"Tengo deadline el viernes en PTD, reorganiza mis prioridades." Claude ajusta el JSON y te lo devuelve listo para importar.
📸
Importar reuniones
Haz una captura de tu calendario de Outlook o Teams y pásasela. Claude extrae las reuniones y las añade al JSON.
💬
Añadir tareas en lenguaje natural
"Añade estas tareas que me han llegado esta mañana..." y le pegas el texto. Claude las estructura y te devuelve el JSON actualizado.
💡
El flujo con Claude: Exportar JSON desde TaskBoard → pegárselo a Claude con tu petición → Claude te devuelve el JSON actualizado → Importar JSON en TaskBoard → Guardar en Drive.

Consejos de uso
Para sacarle el máximo partido
🎯
Máximo 3 tareas ★
Si tienes más de 3 tareas "de hoy", la barra de capacidad se pondrá roja. Es una señal de que necesitas bajar alguna a A.
⏱
Pon siempre el esfuerzo
El esfuerzo estimado en horas es lo que hace que la capacidad del día y la vista semanal sean útiles. Sin él, los cálculos no funcionan.
📆
Reuniones con fecha
A diferencia de las tareas, las reuniones tienen fecha específica. Puedes navegar por la semana en el timeline para ver qué tienes cada día.
🔄
Ritual semanal
Los lunes, pasa las tareas A no completadas a ★ o C, y limpia las D que ya se hayan desbloqueado. Es el momento ideal para pasarle el JSON a Claude.
